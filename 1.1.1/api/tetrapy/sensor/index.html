    Sensor

    source module tetrapy.sensor

    Integrate a convolved spectral library into the tetracorder command tree.

    Once a library has been convolved onto a scene's grid (see :mod:tetrapy.conv), a tetracorder run has to be told about it. That means writing, for a named "sensor", the handful of per-sensor files the command tree looks up by name:

    • restart_files/r1-{name} — the specpr restart file pointing at the convolved reference / research libraries.
    • DELETED.channels/delete_{name} — the channels to drop for this sensor, given as channel numbers or as wavelength ranges resolved against the scene's grid.
    • DISABLE/{name} — which analysis groups and cases are enabled vs. disabled.
    • COLOR.channels/color-{name} — the color-composite channel definitions.

    :func:build writes all four from a sensor config block. The channel count for the restart file is read directly from the scene reflectance raster, so the restart file self-consistently matches the scene being mapped.

    Functions

    • parse_list — Expand a mixed list of ints and "a-b" range strings into a flat int list.

    • parse_channels — Expand a tetracorder deleted-channels spec into a sorted list of channel numbers.

    • format_channels — Compress channel numbers into tetracorder range syntax.

    • wavelength_channels — Find the channels whose centre wavelength falls inside any of the given ranges.

    • resolve_deleted_channels — Resolve a sensor.deleted_channels config value to channel numbers.

    • build — Write the per-sensor tetracorder integration files for a convolved library.

    source parse_list(vals: Iterable[Union[int, str]]) → List[int]

    Expand a mixed list of ints and "a-b" range strings into a flat int list.

    Config lists like [1-5, 18, 20-22] mix plain integers with hyphenated range strings; this flattens them into every integer they cover (ranges inclusive).

    Parameters

    • vals : Iterable[int or str] — Items that are either an integer or a "start-end" range string.

    Returns

    • list[int] — The expanded integers, in the order the items were given.

    Examples 

    parse_list(["1-5", 18, "20-22"])

    [1, 2, 3, 4, 5, 18, 20, 21, 22]

    source parse_channels(spec: str) → List[int]

    Expand a tetracorder deleted-channels spec into a sorted list of channel numbers.

    The spec is whitespace-separated tokens, each a single 1-based channel N or an inclusive range NtM. The terminating c (standalone or attached to the last token, e.g. 280t285c) and any # comment are ignored.

    Parameters

    • spec : str — Deleted-channels spec, e.g. "1t4 75t79 218 280t285c".

    Returns

    • list[int] — Sorted, de-duplicated channel numbers.

    Raises

    • ValueError — If a token is malformed or a range is reversed.

    Examples 

    parse_channels("1t3 7 9t10c")

    [1, 2, 3, 7, 9, 10]

    source format_channels(chans: Iterable[int]) → str

    Compress channel numbers into tetracorder range syntax.

    Consecutive runs become NtM and isolated channels stay as plain numbers. No terminating c is added.

    Parameters

    • chans : Iterable[int] — Channel numbers, in any order; duplicates are ignored.

    Returns

    • str — The compressed spec, e.g. "1t4 218 280t285".

    Examples 

    format_channels([3, 1, 2, 7, 9, 10])

    '1t3 7 9t10'

    source wavelength_channels(ranges: Iterable[Sequence[float]], wavelengths: np.ndarray, units: str = 'um') → List[int]

    Find the channels whose centre wavelength falls inside any of the given ranges.

    Parameters

    • ranges : Iterable[Sequence[float]] — Inclusive [min, max] wavelength ranges, in units.

    • wavelengths : numpy.ndarray — Band-centre wavelengths of the scene grid, in microns.

    • units : str, default="um" — Units of ranges: "um" (or "µm") or "nm".

    Returns

    • list[int] — Sorted 1-based channel numbers matched by any range.

    Raises

    • ValueError — If units is unknown, a value's magnitude does not fit units, or a range is not an ordered [min, max] pair.

    Notes

    A range that matches no channels is logged as a warning, as it usually means a typo or the wrong units.

    source resolve_deleted_channels(spec: Union[str, int, Mapping], rfl: Union[str, Path], nchans: int) → List[int]

    Resolve a sensor.deleted_channels config value to channel numbers.

    Parameters

    • spec : str or Mapping — Either a tetracorder channel spec string (see :func:parse_channels), or a mapping with keys:

      wavelengths : list[[float, float]], optional Inclusive wavelength ranges, matched against band centres of the scene grid. units : str, default="um" Units of wavelengths: "um" or "nm". channels : str, optional Extra 1-based channel numbers in tetracorder spec syntax.

    • rfl : str or Path — Scene reflectance raster; its .hdr supplies the wavelength grid. Only read when wavelengths is given.

    • nchans : int — Number of channels in the scene; every resolved channel must be within [1, nchans].

    Returns

    • list[int] — Sorted, de-duplicated channel numbers to delete.

    Raises

    • TypeError — If spec is neither a string nor a mapping.

    • ValueError — If the spec is malformed, wavelength ranges are given but the header has no usable wavelength grid, or a channel is outside [1, nchans].

    source build(path: Path, sensor: Box, rfl: Union[str, Path]) → None

    Write the per-sensor tetracorder integration files for a convolved library.

    Generates the four files the tetracorder command tree looks up by sensor name — the restart file, deleted-channels file, enable/disable file, and color-channels file — so a subsequent setup/tetrun uses the convolved libraries referenced by sensor.

    Parameters

    • path : Path — Root of the tetracorder command tree (.../tetracorder{version}.cmds). The files are written into its restart_files/, DELETED.channels/, DISABLE/ and COLOR.channels/ subdirectories.

    • sensor : box.Box — The sensor config block. Fields used:

      name : str Sensor name; every written file is keyed on it. reflib / reslib : str Paths to the convolved reference / research specpr libraries, written into the restart file. deleted_channels : str or mapping Either a specpr channel-deletion spec (e.g. "1t4 75t79 ... 226c"), or a mapping of wavelengths ranges (in units, default um) plus optional channels, resolved against the scene's wavelength grid (see :func:resolve_deleted_channels). enable.groups / enable.cases : list Analysis groups and cases to enable (as accepted by :func:parse_list); everything else is disabled. colors : list[str] Lines for the color-channels file.

    • rfl : str or Path — Scene reflectance raster; its band count sets nchans in the restart file, and its .hdr supplies the grid for wavelength-based deleted_channels.

    Notes

    The restart file's specpr "protection numbers" are derived from each library's file size (records of 1536 bytes), matching the specpr convention.

    Raises

    • FileNotFoundError
